# Views
| File | Content |
| --- | --- |
| `_index.js` | Collection file, registers every view of the extension. |
| `view.decorations.js` | Colored bands behind every banner and marks in the scrollbar. |
| `view.codelens.js` | One line above every chapter: position, sections, previous and next chapter. |
| `view.library.js` | The library tree in the explorer: shelves, books, chapters, sections. |
| `view.statusbar.js` | The chapter and section at the cursor, a click opens the quick pick. |
| `view.outline.js` | Outline symbols, breadcrumbs, Go to Symbol and folding ranges. |
